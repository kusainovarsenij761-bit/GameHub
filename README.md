# GameHub — сборка APK автоматически

В архиве лежит исходный Flutter-код и GitHub Actions workflow, который генерирует Android scaffolding и собирает APK в облаке.

## Как получить APK

1. Распакуй архив.
2. Создай новый репозиторий на GitHub.
3. Загрузи в репозиторий всё содержимое этой папки, включая скрытую папку `.github`.
4. Открой вкладку **Actions** в репозитории.
5. Выбери workflow **Build GameHub APK** и нажми **Run workflow** (если workflow не запустился сам после push).
6. Дождись окончания сборки. Если шаги завершились успешно, открой запуск workflow и скачай артефакт **gamehub-release-apk**.
7. Распакуй скачанный артефакт: внутри будет `app-release.apk`. Перенеси его на Android-телефон и установи. Телефон может попросить разрешить установку приложений из этого источника.

## Ограничения и важные детали

- Это неподписанный персональным ключом release APK; Android обычно позволяет установить его, но для публикации и обновлений через магазин потребуется собственная подпись.
- Workflow проверяет форматирование и запускает `flutter analyze`; если сборка выявит ошибки, APK не появится и потребуется исправить ошибки по логу Actions.
- Package ID игр может отличаться у региональных версий PUBG Mobile.
- Android DND подавляет уведомления согласно системным правилам и исключениям, а не гарантирует блокировку всех звонков/SMS.
- Восстановление прежнего DND выполняется при возврате в GameHub, но не гарантируется, если процесс приложения завершён или пользователь остаётся на домашнем экране.
- Это не повышает гарантированно FPS в сторонних играх.
